# Vision

A simplified but robust CAD tool that is light enough to run in a browser, embeds in other cloud apps, and works fully offline on the desktop with no loss of function. It targets engineers (initially marine/structural) who need 2D drafting, curve and surface modelling, attribute-rich parts, clean exchange (STEP, OpenUSD, DXF, PDF), and parametric models that external optimisers can drive.

Non-goals for v1: full solid-feature parity with Creo/NX, implicit/field modelling, DWG, real-time collaboration, in-app optimisers.
